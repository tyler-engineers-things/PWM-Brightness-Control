# PWM-Brightness-Control
Brightness control LED peripheral built for the DE-10 Standard FPGA using VHDL. Utilizes PWM techniques to yield different brightness states.

This Brightness Control Peripheral was developed for ECE 2031 at Georgia Tech as my team's final project submission. In this project, teams were tasked
with developing an advanced LED peripheral that incorporated improved functionality in comparison to the default LED peripheral which simply enables or
disables LEDs. For our project, my team utilized PWM and toggling techniques to incorporate brightness control and toggling functionality into our
project submission. Within the project, I wrote all of our team's VHDL code and much of the SCOMP assembly code as well. This is the first project in
a series of projects I plan on pursuing related to FPGAs, which will be done throughout this upcoming summer.

This repository does not contain all files that were in the Intel Quartus project locally on my PC. This is because this repository contains all files
that were submitted for the class for which this project was completed (ECE 2031). The submission instructions asked for certain files to be omitted,
and those files were also omitted in this repository. If the full project files are desired, send me a message and I can send them to you personally.
